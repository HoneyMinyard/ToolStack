E-Commerce Process Tool Stack

Chronological Workflow & Tooling Analysis

Step 01

Website Building

Core site builders, catalog managers, and static site options categorized by difficulty and capability.

Basics (Standalone Builders)

Wix Site Builder

Provides templates and extensive creative customization options. Wix hosts media directly on their servers, eliminating the need for separate HTML image hosting.

Inventory & Checkout: Supports individual manual uploads or bulk CSV imports (though the CSV template can be messy/confusing). Customers can build carts and checkout, generating automated invoices for both buyer and seller. Requires merchant registration to activate payment processing.

Google Sites

Free and simple UI for beginners. Supports photo galleries, blogs, and hyperlinks, but features limited design flexibility and default font selection unless navigating preset themes.

E-Commerce Capabilities: Lacks native bulk product management. Creating a store requires manual setup without standard product detail pages. Integrates Google Workspace apps (Sheets, Calendar, Forms) by embedding them directly as-is on the page. Uses a standard Google Sites URL unless a custom domain is attached.

Canva Websites

Free static website builder with pre-made templates. Functions similarly to publishing a document as an image-like layout, meaning buttons and images lack interactive website behaviors.

Best Use: Suited for basic, small-scale product catalogs rather than multi-product detail pages. Offers responsive layout toggles for PC and phone viewports, though default URLs cannot be customized.

WordPress

Free, highly customizable platform with continuous page creation, media embeds, Crowdsignal, and payment integrations. Features a steeper learning curve for non-technical users.

E-Commerce Capabilities: Requires the free WooCommerce plugin for structured product listings, categories, and automated inventory management. Without plugins, items must be added manually as individual blog posts without stock controls.

Semi-Automated (Google Sheets Connected)

Sheet Rocket

Connects directly to Google Sheets to display products with promotional badges (Sale, New Arrival, etc.). Customers can build orders and checkout with custom payment instructions (no direct native payment gateway).

Key Limitations: Plain invoice emails sent to both parties. Requires specific column headers. Free tiers break if formulas exist within sheets. Customization is limited to a single accent color (no logo support in header/footer) and restricts items to 1 HTML image URL. Includes embeddable store widgets for external sites.

Shop.Link

Improves upon Sheet Rocket by adding multi-photo support per product via a built-in media library that generates direct URLs. Features built-in analytics, checkout customization, order status tracking, and automated customer emails.

Key Limitations: Google Sheet formulas are not recognized. Design customization remains restricted to one solid color theme (though logo placement is supported). Free plan caps volume at 50 total orders per month (including canceled orders).

SpreadSimple

Combines features of Sheet Rocket and Shop.Link. Supports multiple product photos (utilizing Google Drive hosting tutorials) and background color customization.

Key Advantages: Allows multi-page structures (About, Shop Policies, Contact) and offers integration Add-Ons for Google Maps, HubSpot, Notion, WhatsApp, YouTube, PayPal, and Stripe.

Shearables

Website and widget builder offering styling controls over fonts, colors, and text sizing. Flexible content parameters based on recognized column headers.

Key Limitations: Formulas in connected sheets render as blank text. Free plan limits account to 1 project/widget without add-on access or custom domain routing.

Almost Convenient (AI & Custom Static)

ChatGPT (Static Code Generation)

Generates static HTML/CSS/JS frontend code based on detailed prompts. Can be configured to connect directly to Google Sheets for real-time frontend updates.

Tradeoffs: Requires trial-and-error iterations and lacks live visual previews during build. Form submissions require external backend endpoints or API services to process data without an active web server.

Static Website Generators (Hugo.io & GitHub)

Hugo.io: Fast, command-line static site generator using templates. Requires technical coding knowledge to configure and maintain.

GitHub: Hosts repository source code and frameworks used by static generators like Hugo.

Step 02

HTML Image Hosting

Public image hosting repositories needed to serve direct media URLs for custom and semi-automated sites.

Imgur

Mainstream image platform offering consistent visual quality. Requires image uploads to be public to function reliably across third-party site code.

Pinterest

Organizes assets into board structures. Images must remain set to public to allow external HTML embedding, with quality degradation occurring on unsharp source files.

Google Drive

Provides strong storage capacity and asset management. Note: Certain static website platforms fail to parse Google Drive direct image URLs properly.

ImgBB

Popular free host supporting unlimited uploads up to 35MB per file, custom auto-deletion timers, and album organization.

Note: Generated URLs typically redirect back to the ImgBB landing page rather than serving isolated raw image files.

GitHub Repository

Free, public image hosting solution providing direct raw HTML image links without strict size restrictions or quality compression.

Step 03

Website Hosting

Deployment and domain routing infrastructure.

Cloudflare Pages

Provides free, secure static website hosting with unlimited bandwidth. Custom project domains default to *.pages.dev subdomains unless a custom domain is purchased and connected.

Step 04

Backup System

Version control for custom static and AI-generated builds.

GitHub Branches & Repositories

Essential backup pipeline for non-builder sites. Allows hosting production code on the main branch while testing modifications safely on separate development branches before merging.

Step 05

Ordering System

Workflows structuring how customers select items and submit purchases.

Website Catalogue Only

Workflow: View Catalog → Screenshot/List Items → Submit Order in Instagram DMs → Confirmation & Payment → Status Updates.

Analysis: Centralizes order handling in Instagram DMs. Requires manual listing/screenshots from buyers, which adds steps compared to standard e-commerce flows.

Website Catalogue and Cart

Workflow: View Catalog → Build Cart → Submit Order Request → Confirm & Pay via Instagram DMs → Status Updates.

Analysis: Improves customer UX through a familiar cart layout. An automated email invoice is sent to both buyer and seller; the customer forwards the invoice to Instagram DMs to finalize payment.

Complete E-Commerce Website

Workflow: View Catalog → Build Cart → Checkout & Pay Directly on Site.

Analysis: Full online purchasing flow via direct payment details (GCash/Bank QR). Standard platforms like Wix or WordPress may charge extra transaction fees or default to international gateways like PayPal.

Step 06

Payment System

Direct financial settlement channels.

GCash

Accessible mobile wallet payment method supported via direct phone number entry or scanned QR codes.

Bank Transfer

Direct bank-to-bank settlement method supported via mobile banking apps, account numbers, or Instapay QR codes.

Step 07

Stock Reservation

Strategies for managing inventory allocation and order contention.

Website Automation

Real-time synchronization between the store front-end and master inventory Google Sheets, preventing out-of-stock items from being ordered during high-traffic drop releases.

Manual Management

Operates on a strict "first-to-pay, first-served" rule. Involves manual reservation tracking in DMs, which is effective for low-to-moderate starting transaction volumes.

Transparency Page / Order Tracker

An automated backend progress tracker or customer-facing order status sheet showing real-time reservation and payment verifications to quickly resolve stock disputes.

Step 08

Invoicing Systems

Document generation tools for customer receipts and purchase records.

Free Invoice Generator

Simple browser-based tool supporting top-left logo uploads, multi-currency support, and standard minimal templates (Classic/Slate). Requires manual item input.

Zoho Invoice

Offers 4 layout color themes and structure adjustments. Includes small Zoho footer branding on generated PDFs.

Canva Invoices

Fully customizable and brand-aligned layouts without third-party logos. Requires manual text/price adjustments per order and lacks auto-calculating totals.

AI-Automated Invoicing

Custom script/automation connected directly to the master inventory Google Sheet, generating pre-formatted invoices automatically upon new order entries.
